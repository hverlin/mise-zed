# tree-sitter-mise-bash

[tree-sitter-bash](https://github.com/tree-sitter/tree-sitter-bash) 0.25.1 (`a06c2e4`),
renamed `mise_bash`, for the `mise Shell` language: the shell scripts of mise tasks and hooks,
which `languages/mise/injections.scm` highlights. A grammar of the extension's own, instead of
Zed's `bash`, which belongs to Zed's Shell Script language.

```sh
npm install
npm run generate
npm test
```
